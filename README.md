# Pump.fun graduation bot

Cloudflare Worker that watches Helius webhooks for pump.fun → Raydium migrations and sends
Telegram alerts when a token graduates, then tracks 2x/3x/…/100x moves.

## Secrets

Set these in the Worker (Settings → Variables and Secrets):

- `HELIUS_KEY` — Helius API key (RPC + DAS)
- `TG_TOKEN` — Telegram bot token
- `TG_CHAT` — chat id, or comma-separated chat ids

## Alert fields

In addition to market cap, pool size and socials, graduation alerts now show:

- **Volume 24h / launch** — both in **USD**. 24h comes from DexScreener `volume.h24` for the
  highest-liquidity WSOL pair; launch volume is the SOL traded in pump.fun `Buy` instructions
  before graduation, converted at the SOL/USD price captured at graduation. A `≥` means the
  100-transaction sample was exhausted, so the figure is a lower bound.
- **Trading fees** — estimated fees generated by the token being traded: 1.25% of launch volume
  (pump.fun bonding curve) plus 24h volume × the pool fee rate from GeckoTerminal (defaults to
  1.25% when the pool doesn't publish one). Marked `~` because the post-graduation rate is tiered.
- **Bundled** — share of supply held by top holders whose wallets were all initially funded by
  the same source. The largest 15 token accounts are resolved to owners; each owner's earliest
  funding transaction is inspected; funders with at least 3 holders are treated as bundles.
  LP/burn/program accounts are excluded. If on-chain detection is inconclusive, a Rugcheck
  bundled-risk percentage is used as a fallback.
- **Top10 / Dev** — top-10 holder concentration and creator balance as a share of supply
  (Rugcheck, with an on-chain fallback for Top10).
- **LP** — `burned ✅` when Rugcheck shows the pump.fun/pump_fun_amm market's LP mint burned or
  fully locked with zero circulating LP supply; otherwise `⚠️ not burned` or `n/a`.
- **Dex paid** — shown as a badge only when the token actually has an approved DexScreener paid
  profile. It no longer gates alerts: every graduation is alerted. If the profile is bought later,
  a separate `✅ Dex paid` notification is sent; tokens are watched for up to 60 minutes.

## Why alerts were missed

Two issues were found and fixed:

1. The Dex paid check was used as a gate. Most graduations never buy a paid DexScreener profile
   within the 20-minute pending window, so they expired without an alert. It is now a badge only.
2. `getTransaction` requested `maxSupportedTransactionVersion: 0`, but current pump.fun trades are
   version 1 transactions and were rejected. The worker now requests version 1 (which also reads
   legacy transactions).

All metric calls are best-effort: if an API is slow or rate-limited, the alert still goes out
and the unavailable figure is omitted or shown as `n/a`.

Each enriched graduation alert uses roughly a dozen Worker subrequests (most Helius calls are
batched). On the free Workers plan the 50-subrequest limit can be reached if a single webhook
delivery contains several migrations at once — a paid Workers plan, or a queue, avoids that.

A Rugcheck link is appended to the usual DexScreener / Pump.fun links.

## Deploy

```bash
npm install -g wrangler
wrangler secret put HELIUS_KEY
wrangler secret put TG_TOKEN
wrangler secret put TG_CHAT
wrangler deploy
```

Point your Helius webhook (transaction type: pump.fun migration) at the Worker URL. `GET /test`
sends a connectivity message to the configured chats.
